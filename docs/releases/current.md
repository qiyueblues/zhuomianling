# 桌面灵 1.6.1

## 更顺畅的软件更新

- 在主页确认更新后，下载并校验完成会自动安装，安装结束自动打开新版，主页一次性提示“已更新至 x.x.x”，无需再次点击。
- 更新安装窗口换上与桌面灵一致的浅色界面，蓝色进度条加入流光动效；首次安装仍保留正常向导。
- 下载期间可以取消，关闭下载窗口也会取消；编辑器中须先保存并返回主页，再开始更新，避免未保存内容被安装流程中断。
- 继续提供国内推荐下载和 GitHub 备用下载，查看更新内容不需要连接 GitHub；普通退出不会自动安装。

## 记忆备份与恢复

- 记忆书顶部新增导入，与导出并列；统一使用 `.zmlmem` 备份格式，替代原来的 Markdown、JSON 导出。
- 备份包含有效记忆、分类、标签和时间，也可明确选择包含已保留的来源对话。
- 选择备份文件后可先查看记忆条数，再确认恢复到当前桌宠；自动跳过重复记忆，保留已有记忆和你的编辑，不更改记忆设置。
- 也可以将备份导入其他桌宠；损坏或不兼容的文件会明确提示，恢复失败不会留下只导入一半的记忆。

## 更准确、更轻巧的记忆

- 聊天回忆往事时，可以结合已保存的对应来源对话，帮助 AI 理解当时说了什么、是谁说的。
- 你编辑后的记忆优先于旧对话，已忘记的内容不会继续作为记忆使用；没有来源时仍可使用记忆摘要。
- 改善大量记忆的同步效率和中断恢复，清空后不再重复处理旧内容。
- 自动清理不再需要的历史同步数据，减少长期使用后的磁盘占用。

## 稳定性修复

- 改善 AI 连接设置的保存可靠性，减少保存失败或软件意外退出后需要重新配置的问题。
- 删除桌宠时即使清理中断，也会在下次启动继续完成，并保护其它桌宠的数据。
- 使用旧软件打开新版配置时会明确提示，保留原文件，其它兼容桌宠仍可正常使用。

## 下载与升级

- Windows 安装版：`zhuomianling-setup-1.6.1.exe`，推荐使用。
- Windows 免安装版：`桌面灵.exe`，下载后手动替换程序。
- 1.6.0 可检测本次更新；从 1.6.0 升级时仍沿用旧版的下载后确认步骤。新的自动安装流程从 1.6.1 起生效；1.5.0 及更早版本需手动下载安装。
- 升级保留本机桌宠、模型、聊天、API Key 和记忆数据；请先保存正在编辑的内容。
