# 桌面灵 1.6.0

## 自动更新与国内下载

- 启动完成后自动检查稳定版，主页也可手动检查；支持稍后处理和“不再提示此版本”，后续新版本仍会提醒。
- 新增“更新内容”按钮，下载前、下载中和下载完成后都能查看本次变化。
- 版本检测、更新说明和推荐下载统一使用国内 OSS，查看说明不依赖 GitHub；同时保留 GitHub 备用下载和发布页入口。
- 安装版可在软件内下载，显示来源、进度和速度，支持随时取消及重试；下载校验完成后，由你确认“重启并安装”，普通退出不会自动安装。
- 两种下载来源核对版本、文件大小和 SHA-512，避免来源不同步时下载错误版本。

## 语音模型与连接

- 新增 GPT-SoVITS V5 Dev、V5 Turbo 模型选项，支持配置保存、桌宠包导入导出及对应的运行配置。
- 连接和导入时检查 V5 运行文件、vocoder、LoRA 版本及对应底模，缺失或版本不匹配时给出提示；采样参数沿用服务端的模型默认值。
- 语音连接测试增加一次固定短句的真实合成，帮助发现“接口能连接但无法生成声音”的情况。
- 本地语音服务按桌宠分配运行端口，遇到默认端口被占用时选择可用端口，减少不同桌宠或其他服务之间的冲突。

## 视觉与桌宠包修复

- 完善 DeepSeek 视觉模型识别：支持 V4 Flash Vision Exp，并按版本识别 V4.1 及后续版本；旧版纯文本模型仍保留原有判断。
- 修复带视觉 AI 配置的桌宠包导入及相关配置清理可能卡住的问题。
- 修复桌宠包导入、导出在结束或异常时仍显示忙碌的问题，并避免导出进度混入其他操作。
- 补充 V5 配置教程、资源依赖检查说明和相关回归测试。

## 下载与升级

- Windows 安装版：zhuomianling-setup-1.6.0.exe，推荐使用。
- Windows 免安装版：桌面灵.exe，下载后手动替换程序。
- 1.6.0 是首次加入自动更新的版本。1.5.0 及更早版本需先手动下载安装 1.6.0，之后才能自动检测后续更新。
- 升级保留本机桌宠、模型、聊天、API Key 和记忆数据；请先保存正在编辑的内容再安装。
