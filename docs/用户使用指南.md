# 用户使用指南

这份指南说明如何在桌面灵里创建、配置和使用自己的桌宠。桌面灵默认不自带角色模型、声音模型和 API Key；你需要导入自己拥有使用权的 Live2D 模型，并按需要配置聊天和语音能力。

## 1. 打开桌面灵

安装后运行“桌面灵”。打开后会进入主页。

主页左侧是本机已经创建的桌宠列表，右侧是当前选中桌宠的详情区。

你可以在主页完成这些操作：

- 查看已有桌宠
- 创建新桌宠
- 查看桌宠详情
- 预览已导入的 Live2D 模型
- 启用或关闭桌宠窗口
- 进入编辑器修改配置
- 连接或关闭声音模型
- 删除本地桌宠

如果某个桌宠显示“待导入”，说明它还没有可用的 Live2D 模型。你需要先进入编辑器导入模型，导入成功后才能启用。

## 2. 创建新桌宠

在主页点击“创建新桌宠”，会进入“桌宠设置”页面。

设置页面左侧包含这些栏目：

- 基础信息
- Live2D
- 界面主题
- AI设置
- 语音系统

其中“AI设置”下包含：

- LLM配置
- 角色人设
- 事件配置
- 表现映射

“语音系统”下包含：

- 语音输入
- 声音模型

新桌宠必须先保存“基础信息”。保存成功后，软件才会为它创建本地数据目录，之后才能继续导入 Live2D、配置 AI、保存表现映射、保存事件和配置语音。

如果当前页面有未保存修改，切换栏目或返回主页时会出现提醒。确认离开会丢失当前页面尚未保存的内容。

## 3. 基础信息

基础信息会显示在主页列表和详情区。

必填内容：

- 名称

可选内容：

- 头像
- 简介
- 角色定位
- 性格描述
- 适合场景

头像支持：

- PNG
- JPG
- JPEG
- WebP

选择头像后会进入裁剪窗口。拖动蓝色方框可以调整裁剪位置，滚动鼠标滚轮可以调整裁剪大小。确认后点击“保存头像”。

“适合场景”可以选择已有标签，也可以输入自定义标签后点击“添加场景”。

填写完成后点击“保存”。保存成功后，这个桌宠会出现在主页列表里。

## 4. Live2D 导入

进入“Live2D”页面后，可以导入模型。

你需要选择的是完整 Live2D 模型文件夹，不是单独选择入口文件。可以点击“选择文件夹”，也可以把模型文件夹拖入导入区域。

当前支持：

- Cubism 2：`model.json` / `.moc`
- Cubism 3 / 4 / 5：`.model3.json` / `.moc3`

导入流程分为三步：

1. 选择模型文件夹
2. 检查模型资源
3. 保存桌宠

选择文件夹后，软件会自动检查：

- 模型入口
- Moc 文件
- 贴图
- 动作
- 表情

资源检查通过后，可以点击“预览模型”。预览中可以确认：

- 模型是否正常显示
- 贴图是否完整
- 模型大小和位置是否合适
- 动作是否能播放
- 表情是否能切换

预览区里可以点击动作或表情进行测试，也可以点击“重置状态”让模型回到默认状态。确认没有问题后，点击“保存”。

保存成功后，Live2D 页面会显示“Live2D 模型已导入”，并显示模型入口、贴图数量、动作数量和表情数量。已导入后仍然可以：

- 导入新模型
- 测试动作/表情
- 返回已导入模型

如果模型文件夹缺少入口声明，页面可能会出现“自动声明”按钮。点击后，软件会尝试为当前文件夹生成可用入口。

## 5. 界面主题

“界面主题”用于设置这只桌宠的界面外观。

主题会影响：

- 右键快捷菜单
- 聊天框
- 字幕气泡

内置主题包括：

- 软糖风
- 摇滚风
- 像素风
- 手账风
- 赛博风
- 极简风

选择主题后点击“保存”。主题是按桌宠单独保存的，不同桌宠可以使用不同主题。

如果你有主题 JSON 文件，也可以点击“导入主题”。读取后点击“保存”，主题会完整写入当前桌宠配置，只属于当前桌宠，不会加入全局主题库或影响其它桌宠。主题可分别设置标题栏、输入区、用户与桌宠气泡材质，以及装饰主次色和水印色；还可独立定义快捷菜单的基础卡片、中心按钮、活动态和各个操作的材质。主题还可通过受控枚举为聊天框的左/右标题区、右上外框和正文水印选择应用内置装饰图标，不能引用外部图片、CSS 或脚本。切换并保存内置主题只会改变当前使用的外观，导入主题仍会保留在当前桌宠中；只有点击导入主题卡片上的删除按钮并保存后才会移除。

## 6. LLM 配置

进入“AI设置 / LLM配置”，可以配置文字聊天模型。

你需要填写：

- 服务商
- Base URL
- API Key
- 模型名

服务商可以选择预设项，也可以选择“自定义”后手动填写兼容 OpenAI 接口的地址。

点击“连接”后，软件会尝试读取可用模型列表。如果读取成功，可以从下拉列表选择模型；如果没有读取到列表，也可以手动填写模型名。

点击“保存设置”后，这只桌宠会保存当前 AI 配置。API Key 只保存在本机，重新填写可以覆盖旧 Key。

保存连接或点击“测试输出”时，软件会用不含人设、聊天和记忆的固定内容检测当前模型的回复能力。设置页会显示两种能力之一：

- **完整桌宠协议**：支持每轮心情变化；配置表现映射时支持 AI 语义表情；文字与声音语言不同时支持独立翻译朗读。
- **仅文字兼容**：稳定完成文字聊天和自动记忆；本轮心情不变化，表情由本地根据正文推断，同语言可以朗读正文，跨语言语音会静默降级为纯文字。

如果服务不支持 `response_format`，但模型能按照提示稳定返回完整 JSON，设置页会显示“完整桌宠协议 · Prompt JSON 兼容”；这种情况仍然支持每轮 `reply`、心情变化和按需跨语言语音，不属于纯文本降级。“仅文字兼容 · 自动回退”才表示后续聊天使用真正纯文本。你可以在服务恢复或更换模型后重新点击“测试输出”。认证失败、限流、网络故障、服务端错误以及单轮字段缺失都不会被误记为永久能力降级。

如果连接或保存失败，优先检查：

- Base URL 是否正确
- API Key 是否有效
- 模型名是否存在
- 当前网络或本地代理是否可用

## 7. 角色人设

进入“AI设置 / 角色人设”，可以填写桌宠的人设。

主要输入框是“我是谁”。这里可以写：

- 桌宠身份
- 性格
- 说话方式
- 和用户的关系
- 喜欢或讨厌的事物
- 回答时需要遵守的边界

你还需要选择“文字输出语言”：

- 中文
- 日语
- 英语

“你希望回复长度”可以选择：

- 短
- 中
- 长

回复长度可以不勾选。保存后，这些内容会影响桌宠聊天时的回答风格。

## 8. 表现映射

进入“AI设置 / 表现映射”，可以把 Live2D 模型里的动作和表情整理成桌宠能理解的表现。

使用前请先完成 Live2D 导入。

导入模型时，软件会自动读取其中的：

- 动作源文件
- 表情源文件

识别完成后，页面会分成“动作”和“表情”两个列表。每一行包含：

- 源文件名
- 桌面预览按钮
- 映射 key
- 动作描述或表情描述

源文件名由导入时自动识别，不能手动修改。点击“预览”会打开或切换到当前桌宠的桌面窗口并播放该资源；你可以边看效果边填写映射 key 和中文描述。

示例：

```text
angry01.mtn          [预览]    key: angry      描述：生气皱眉
smile.exp3.json      [预览]    key: happy      描述：开心微笑
idle.motion3.json    [预览]    key: idle       描述：待机动作
```

映射 key 是给事件配置和 AI 回复引用的名称。建议使用简短英文，例如：

- normal
- happy
- angry
- surprised
- shy
- nervous
- panic
- thinking
- idle

映射 key 必须以英文字母开头，只能包含英文、数字、下划线或短横线，并且不能重复。

中文描述用来告诉你和 AI 这个表现是什么意思。建议写具体一点，例如“开心微笑”“慌张后退”“认真思考”“生气皱眉”。

不想使用的源文件可以留空。只有填写了有效 key 和描述的行，才会作为可用表现保存。

表现映射页面还有“随机”功能。开启后，AI 回复时会在你选择的范围内随机播放动作或表情。随机范围可以选择：

- 动作
- 表情
- 全部

开启随机后，下方映射编辑会暂时锁定。关闭随机后，AI 回复会重新按映射描述选择表现。

## 9. 事件配置

进入“AI设置 / 事件配置”，可以为桌宠的不同行为设置反馈。

使用前请先完成 Live2D 导入。动作和表情源会在导入时自动识别；在事件配置中选择资源后，可点击“预览”直接在桌面桌宠中确认效果。

当前可以配置的事件包括：

- 模型加载完成
- 点击模型
- 连续快速点击
- 拖拽模型
- 打开聊天
- 关闭聊天
- 开启穿透
- 关闭穿透
- 长时间无操作
- 关闭桌宠

每个事件可以设置：

- 触发动作
- 触发表情
- 表情持续时间
- 候选台词

“动作”和“表情”来自已经保存的表现映射。候选台词可以写多条，事件触发时软件会从中随机选择一条显示。

如果某个事件不需要动作、表情或台词，可以留空。

## 10. 启用桌宠

回到主页，点击一个已经导入 Live2D 模型的桌宠。

详情区会显示：

- Live2D 预览
- 当前启用状态
- 声音模型状态
- 界面主题
- 桌宠详情

点击“启用桌宠”后，会打开透明无边框桌宠窗口。

桌宠窗口中右键点击模型区域，可以打开圆形快捷菜单。常用操作包括：

- 对话：打开或关闭聊天框
- 触控：开启后可以拖动桌宠窗口
- 穿透：让桌宠尽量不阻挡桌面操作
- 关闭：关闭桌宠窗口
- 中心按钮：收起菜单

开启“穿透”后，其他菜单按钮会隐藏，只保留“解锁”入口。鼠标进入桌宠模型区域时才会显示这个入口；入口以外的区域仍保持穿透，不会影响桌面下层窗口的点击。将鼠标移到“解锁”入口后点击它，桌宠会恢复正常交互。

## 11. 聊天

启用桌宠后，右键打开快捷菜单，点击“对话”即可打开聊天框。

如果已经配置好 LLM，输入文字后桌宠会根据人设回复。

如果还没有配置 AI，聊天可能无法得到回复。请先到“AI设置 / LLM配置”保存可用的模型连接。

如果已经配置表现映射，AI 回复时可以根据语境触发表情或动作；如果开启随机表现，则会按随机范围播放动作或表情。

当前模型显示“仅文字兼容”时仍可正常聊天。这种模式不会要求模型输出 JSON，也不会伪造心情、表情或跨语言朗读字段；如果聊天文字与声音模型语言不同，本轮只显示文字，不会把错误语言送去朗读。

## 12. 语音输入

进入“语音系统 / 语音输入”，可以配置语音转文字。

语音输入是可选功能。未配置时，文字聊天仍可正常使用。

当前语音输入使用腾讯云实时语音识别。你需要填写：

- AppID
- SecretId
- SecretKey

填写后点击“连接”。连接成功后，可以继续配置语音输入参数。

可设置项包括：

- 自动识别说话结束
- 静音超过 1 / 2 / 3 秒自动结束
- 音量阈值
- 回复后继续录音

普通房间可以先使用 18% 左右的音量阈值。环境越吵，阈值可以调高；说话声音越轻，阈值可以调低。

保存后，聊天框中会显示语音输入入口。语音输入需要你主动触发，软件不会后台偷偷录音。

## 13. 声音模型

进入“语音系统 / 声音模型”，可以配置语音回复。

语音回复是可选功能。未配置时，桌宠仍可正常文字聊天和显示字幕。

语音回复需要你准备本机 GPT-SoVITS 环境和声音资源。

你需要填写或选择：

- GPT-SoVITS 本地路径
- 模型版本（需要与训练权重对应）
- SoVITS 模型
- GPT 模型
- 参考音频
- 参考文本

选择声音资源后点击“连接”。连接成功后，页面会自动打开“启用语音回复”。

可设置项包括：

- 输出语言：中文、日语、英语
- 播放模式：逐句播放、完整生成后播放
- 语音与文字一起输出

如果开启“语音与文字一起输出”，软件会等待语音生成完成后，再同时显示文字并播放语音。

如果声音模型已经配置完整，也可以在主页详情区点击“声音模型”直接连接或关闭声音。

连接失败时，优先检查：

- GPT-SoVITS 本地路径是否正确
- 模型版本是否与 GPT / SoVITS 权重对应
- SoVITS 模型是否存在
- GPT 模型是否存在
- 参考音频是否存在
- 参考文本是否填写
- 本地 GPT-SoVITS 服务是否可用

语音失败不会影响文字聊天和字幕显示。

## 14. 记忆书

在桌宠详情页点击“记忆书”可以进入该桌宠独立的长期记忆页面。第一次进入时会出现启用仪式：

- 选择启用后，默认打开“对话召回”和“自动整理”，关闭“保留原始来源”
- 选择暂不启用只关闭本次仪式，下次重新进入仍会询问
- 每只桌宠单独设置、单独保存，彼此不会共享记忆

记忆书包含“关于你、偏好习惯、重要事件、关系与目标”四个章节，可以搜索、按时间筛选、手动新增或编辑、标记重要、忘记并短暂撤销。页面顶部的“导出”统一保存为 `.zmlmem` 记忆备份，可以选择是否包含已保留的来源对话；不再提供 Markdown 或 JSON 文本导出。

点击同一页面的“导入”，选择 `.zmlmem` 文件，程序先校验完整性、格式版本和记忆来源关联，再显示备份条数供确认。点击“确认恢复”后合并到当前桌宠，无需再次选择桌宠；已有记录保留，重复记录跳过，不覆盖现有记忆。来源对话随备份一起恢复，记忆设置保持当前值。单次备份最多 10000 条记忆，解压数据不超过 64 MiB。恢复时索引服务不可用不会丢失已保存的记忆，可稍后重建索引。

从记忆书返回主页后，再次进入会重新从目录页开始，并清除上一次阅读会话中的章节选择、搜索筛选、页码和滚动位置；记忆正文与设置不会受到影响。

记忆正文保存在本机 SQLite 账本。中文语义检索使用安装包自带的 BGE INT8 模型，并结合本地关键词和精确匹配；不会为了检索而把中文翻译成英文，也不会调用云端 embedding。模型只在首次实际召回、写入索引或主动重建时加载，因此不会拖慢主窗口启动；首次使用可能出现短暂预热，之后会复用常驻 sidecar。

“自动整理”与本地检索不同：开启后，一轮聊天完整成功时，当前用户消息和最终可见回复会发送给你配置的整理 AI，以提取少量结构化记忆。除用户明确表达的长期信息外，双方确认的称呼与约定、真实发生的共同经历，以及桌宠明确作出的具体承诺也可以成为记忆。普通客套话、一次性表演、即时情绪、无依据的桌宠爱好或经历，以及核心人格变化不会自动保存。关闭自动整理不会影响手动管理已有记忆。关闭召回后，聊天模型不会收到记忆上下文。

开启“保留来源对话”后，自动记忆的详情页会提供“查看来源对话”入口。这里只展示生成该条记忆所依据的一轮用户消息、桌宠最终回复、对话时间和整理时间，并且不会展示本机文件路径。记忆后来经过编辑时，来源仍保持原样，只用于追溯整理依据；没有开启来源保留的旧记忆会显示“未保存”。

SQLite 账本是权威数据。索引损坏或模型升级时可以从账本重建，不会用空索引覆盖账本。删除桌宠会同时删除该桌宠的账本、pending 和派生索引。

## 15. 删除桌宠

在主页选中桌宠后，可以点击详情区里的“删除”。

删除会移除这只桌宠的本地配置和相关本地资源。删除前请确认已经备份需要保留的模型、头像、台词、人设或语音配置。

## 16. 本地数据与隐私

桌面灵是本地优先的软件。

你创建的桌宠、头像、Live2D 模型、AI 设置、人设、表现映射、事件台词、语音设置和记忆账本都会保存在本机。

软件默认不会上传这些内容。更换电脑或重装系统前，请自行备份需要保留的桌宠数据。

请不要把以下内容发布到公开仓库或分享给不可信的人：

- API Key
- 腾讯云 SecretId / SecretKey
- 未授权 Live2D 模型
- 声音模型
- 参考音频
- 本地绝对路径配置

安装包自带的 BGE 模型是通用中文检索模型，不包含任何用户记忆或预置角色数据。
## 17. 心情系统

每只桌宠拥有独立的 `-100～100` 心情值，并分为黑化、低迷、失落、平静、愉快、喜悦和兴奋七个固定区间。点击、快速点击、完成拖拽和打开聊天会按固定冷却规则影响心情；发生变化后先保持 10 分钟，随后每 5 分钟向平静回落 1 点。关闭应用期间不会后台运行，但下次读取时会按经过时间结算。

编辑器“心情”页可为每个固定区间选择进入动作或表情，并导入当前桌宠专用的 3～10 秒 GPT-SoVITS 参考音频。区间音频缺失或失效时只向平静方向逐级降级，不会跨到相反情绪侧。本轮 AI 与全部流式语音分句会锁定请求开始时的同一心情和语音快照，本轮结束后的变化只影响下一轮。

桌宠右键快捷菜单的“心情”按钮会显示只读胶囊。拖动胶囊只保存该宠物的显示位置，不能直接修改心情值。心情数值、内部提示、AI 的 `moodDelta` 和本机音频路径不会进入聊天正文、字幕、TTS 文本、记忆或来源对话；所有音频都保存在本机当前宠物目录中。

## 18. 分享与安装 `.zmling` 桌宠包

主页顶栏的“导入桌宠”会先打开导入说明页；阅读检查说明并点击“选择 `.zmling` 文件”后，才会打开系统文件选择窗口。软件随后检查 ZIP 结构、文件路径、大小、压缩比和每个文件的 SHA-256，再在隔离 staging 中检查 Live2D 与语音资源；检查失败或取消不会留下半成品桌宠。

如果原桌宠配置过 AI，导入向导会要求选择与现有 LLM 设置一致的 DeepSeek、OpenAI、Gemini 预设或自定义 Base URL，再填写自己的 API Key。连接成功后向导会显示服务返回的模型列表，选择模型后执行输出能力检测；服务名称由 Base URL 自动识别，不能手动伪造。原作者的 AI 连接信息不会进入包。如果桌宠启用了 GPT-SoVITS，向导只要求选择本机 GPT-SoVITS 完整目录；包内已经包含声音模型与参考音频，安装前仍会完成一次真实语音合成检测。腾讯云录音配置不会导入。

已保存且没有未保存修改的桌宠，可以从编辑器顶栏右侧点击“导出桌宠”，然后选择保存位置。导出包含角色配置、完整 Live2D、头像、已导入的自定义主题和桌宠语音资源；即使当前使用系统内置主题，只要没有手动删除导入主题，主题定义也会一并保存。

`.zmling` 明确不包含：

- API Key、AI Base URL、模型连接元数据和腾讯云凭据。
- GPT-SoVITS 程序根目录或其它本机绝对路径。
- 记忆账本、来源对话、pending、派生索引和记忆设置。
- 当前心情值、桌面窗口位置或其它运行期私有状态。

`.zmling` 是便于分享的流式 ZIP 容器，不是加密、密码保护或 DRM 格式。收到文件的人可以读取其中的模型、贴图、声音权重和音频。只有在你拥有这些资源的复制与分发权时才可以导出或分享。
